# 档案装盒编目与库位盘点系统

全宗 / 案卷 / 档号 / 盒号 / 密级 / 装盒清单 / 库房 / 货架 / 借阅状态 / 盘点差异 的一体化管理。
**零第三方依赖**：仅使用 Python 3 标准库（`sqlite3` + `http.server`）。
所有档案均为**虚构编号**，不上传任何真实文件；盘点附件只在本地目录登记虚构编号的占位文件。

## 一条命令启动

```bash
python3 run.py            # 首次启动自动建库并播种编目/入库/盘点样例
# 打开 http://127.0.0.1:8000
```

常用参数与环境变量：

| 用法 | 说明 |
|---|---|
| `python3 run.py --reset` | 清空本地数据后重新生成样例 |
| `python3 run.py --no-serve` | 只建库播种，不启动服务 |
| `python3 run.py --port 8090` | 指定端口 |
| `ARCHIVE_HOME` | 数据目录（默认 `./data`，含 `archive.db` 与 `attachments/`） |
| `ARCHIVE_REMINDER_INTERVAL` | 进程内提醒扫描间隔秒数（默认 20） |

启动后样例包含：1 个全宗、21 条虚构案卷、5 个盒（含连续装盒与断档切盒）、
2 个库房共 8 个库位、1 张已完成移位单、1 笔正常借阅、1 笔超期借阅、
1 个进行中（已冻结）的盘点任务及少件/标签损坏差异。

## 功能页面

| 页面 | 内容 |
|---|---|
| 总览 | 关键指标、进程内提醒、待处理差异 |
| 案卷编目 | 全宗、案卷登记、档号自动生成、按年度+保管期限的装盒建议（断档提示） |
| 装盒清单 | 盒号/盒密级/盒内连续档号、入库绑定库位 |
| 库位地图 | 库房→货架→层位网格，空位/在库/在借/移位中可视化；移位单开单与交接 |
| 盘点任务 | 建单冻结、逐盒清点（相符/缺盒/错盒/标签损坏/少件/缺卷档号）、附件登记、确认 |
| 借阅审批 | 申请（幂等键）、批准/驳回、出库借出、归还；**审批状态与归还期限为主列** |
| 差异处理 | 六类差异**按库位聚合**，处理登记、补录（必须注明依据） |

## 核心业务规则

- **档号唯一**：`全宗号-年度-期限码(Y/D30/D10)-序号`，数据库 UNIQUE 约束兜底。
- **装盒连续不重复**：同一全宗/年度/期限内按序号切盒（默认每盒 10 件），
  序号断档（疑似缺卷）处强制切盒并在建议页标红提示。
- **入库才绑定库位**：装盒后盒无库位；入库时绑定库房/货架/层位并校验容量。
- **调架先开单**：移位单 `待出库 → 在途 → 已交接`；交接完成后库位才变更；
  在途中止退回原库位并生成「移位中断」差异，后续完成交接可自动闭环该差异。
- **盘点冻结**：任务创建即冻结范围内盒的入库/调架/出库借出；
  **确认盘点只固化结论、解除冻结，绝不直接改库存**；补录必须填写依据。
- **六类差异**：缺卷、错盒、标签损坏、盘点少件、移位中断、借阅超期。
- **借阅互斥与幂等**：申请可携带幂等键，重复提交返回原单；
  同一盒两名人员同时点「借出」时，数据库原子条件更新保证**只有一人成功**。
- **密级与岗位脱敏**：密级 `公开 < 内部 < 秘密 < 机密`；
  库位字段仅库房岗（管理员/库管）可见；借阅字段仅借阅岗与审计岗可见；
  标题按本人密级显示（越权显示占位符），**档号始终保留**以便盘点核对。

岗位（右上角切换身份，演示环境无密码）：
管理员 / 编目员 / 库管员 / 借阅员 / 审计员，各岗位操作权限与可见字段不同。

## 数据存放

- SQLite：`data/archive.db` —— 档号、盒号、库位、移位单、盘点、差异、借阅全部落库。
- 盘点附件：`data/attachments/task_<id>/box_<id>/` —— 仅虚构编号文本占位，无真实档案内容。
- 进程内提醒：后台守护线程周期扫描，生成「将到期 / 已超期 / 盘点冻结中」提醒并落库展示。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖（41 个用例）：

- **档号唯一**：自动/显式档号冲突、跨期限唯一、数据库约束、连续装盒与断档切盒；
- **移位交接**：开单不动库位、在途、交接落位、重复开单拦截、中断退原位出差异、满位交接拒绝；
- **密级权限**：岗位操作矩阵、库位/借阅/标题脱敏、档号保留；
- **盘点冻结**：冻结拦截借出与调架、范围限定、缺盒/缺卷/错盒/标签损坏/少件差异、
  确认不改库存、确认后补清点被拒、补录必须注明依据、差异按库位聚合；
- **借阅幂等**：幂等键返回原单、**两线程并发同盒借出仅一人成功**、超期差异与归还闭环。

## 目录结构

```
app/
  config.py       配置与数据目录
  db.py           SQLite 连接与建表
  security.py     岗位/密级权限与脱敏
  services.py     全部领域规则（编目/装盒/入库/移位/盘点/差异/借阅/提醒）
  attachments.py  本地附件目录
  seed.py         虚构样例数据
  web.py          http.server 路由与服务端渲染页面
run.py            单命令入口（建库 + 播种 + 提醒线程 + Web 服务）
tests/            unittest 用例
```
